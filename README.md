# Portfolio web — Jesús Castro V16

Versión con el reel definitivo del TFM integrado directamente en la página y el nuevo demo **SOMBRÍA**.

## Visualización local

Abra `index.html` desde un servidor local para que los reproductores de YouTube/Drive funcionen correctamente. El audio del portfolio y el reel están incluidos en la carpeta `assets`.

## Contenido destacado

- Reel TFM: `assets/reel-castromusic.mp4`
- Audio: DOOM, The Blade of a Thousand Tears, IN THE POOL
- Demos: World of Warcraft, Cortometraje infantil, Fragmento cinematográfico, Joker y Sombría
